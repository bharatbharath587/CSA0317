🎓 B.Tech Project Defense & Viva Voce Q&A

Q1: Why use a Binary Max-Heap instead of a Sorted Array for Priority Matchmaking?

A sorted array requires O(n) time for every insert because elements must shift. A Max-Heap achieves O(log n) insertions and O(log n) extractions using array arithmetic without pointer overhead.

Q2: How does the priority formula prevent player starvation in the heap?

Priority = Skill Rating (MMR) + (Wait Time × 1.5). As average-tier players wait longer, their priority score continuously increases, guaranteeing they bubble up toward the root to be matched.

Q3: Where is FIFO Queue used versus Priority Heap in real games?

FIFO queues are used for casual/unranked matchmaking and server login queues (strictly arrival-based). Heaps are used for competitive ranked modes and tournament seeding (skill-based).

Q4: What are the array indexing formulas for a complete binary heap?

For node at index i: Parent = (i-1)//2, Left Child = 2i+1, Right Child = 2i+2.

Q5: How does the Arpad Elo rating system work?

Expected win probability is E_A = 1 / (1 + 10^((R_B - R_A)/400)). Rating adjustment is ΔR = K × (Actual - Expected) with K=32. Underdogs gain large Elo bonuses when defeating top players.
